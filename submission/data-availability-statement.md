## 2. Recommended wording — primary version (for the manuscript)

> **Data Availability Statement**
>
> This Perspective reports no new experimental data. All quantitative values discussed are drawn from the published literature and are attributed to their sources by DOI in the reference list. The reduced model described in the Supporting Information, together with the scripts that generate the figures and the numerical audit scripts that re-derive the manuscript's order-of-magnitude estimates, are openly available at **[repository name]** under DOI **[TO BE FILLED BY AUTHORS — the DOI does not exist yet; register the deposit, then paste the real DOI here]**, and are also provided as Supporting Information with this article.

> **Why there is no DOI string here even as an example.** Earlier drafts of this file carried an illustrative Zenodo-style placeholder DOI. That is a *reserved-prefix placeholder*, not a resolvable identifier, but the project's reference auditor extracts anything DOI-shaped and reported it as a 404 — correctly, because a reader who tried it would get one. **Do not paste a fake DOI, even as an example, into a file that a DOI-extraction script reads.** Register the Zenodo/Figshare deposit first, then insert the real identifier.

**Word count:** 79 (whitespace tokenisation). **Note the two-mechanism answer** — repository *and* SI — which satisfies both halves of the journal requirement (community-trusted repository link; scripts archived publicly). Providing both is deliberate: the SI guarantees the reviewer sees the code even before a repository is indexed, and the DOI makes it citable.

## 4. Two things not to disclose carelessly

**(a) The superseded model versions.** `loopA_model_prototype.py`, `_v2.py` and `_v3.py` are retained only as documented negative results; the dossier states they diverge, return unphysical values, or were superseded (`07-final/DOSSIER.md` §9 item 9). If they are deposited, the deposit **must** label them as negative results and point to `loopA_model_v4.py` as authoritative. An unlabeled deposit containing four model files, three of which are wrong, invites a reproducibility complaint. **Either label them or exclude them.**

**(b) Do not claim a repository DOI that does not exist.** The statement above contains `[TO BE FILLED BY AUTHORS]` rather than an invented DOI. A fabricated or premature DOI in a mandatory statement is a serious integrity problem, not a placeholder-level inconvenience.
